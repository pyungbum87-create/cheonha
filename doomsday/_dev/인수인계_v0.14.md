## v0.12~0.14 (2026-11-14) — 개선 설계서(Claude Doc '둠스데이 익스프레스 개선 설계서') 3단계 반영
### 1단계 (v0.12)
- 물대포·냉동·환풍기 = 액티브 스킬(쿨 12/18/15초, 오른쪽 동그란 버튼). 자동 모드면 80% 효율로 알아서. 준비되자마자 누르면 타이밍 보너스 +15%
- 원소 반응 5종: 물+전기 감전(2배+젖은 좀비 연쇄) / 물+얼음 즉시 빙결 / 얼음+물리 산산조각 / 불+바람 불회오리 / 불+물 수증기(느려짐). 처음 일어나면 큰 글자 + save.reactions(도감)
- 판 안 제한: 무기 4(기관총 포함)·보조템 4·진화 2. 진화 = 4레벨 + 짝 보조템(evoWith) → 중간보스 보물상자에서만
- 드래그 = 기관총 직접 조준(+30%, 보스 약점 1.5배). E.unproject 추가
- 구조 작전(rescueOps): 구조 신호 → 멈춘다/지나친다(3초). 작전 = 미니게임(sniper·rescue·boiler·hack). 지나치면 다음 장에 그 사람이 좀비로
- 안전 칸: 시민 6명마다 칸 추가, 창문에 얼굴(atlas 2장째 face:0~11, face:dog). 직업 보너스(jobs) 같은 직업 3명이면 2배. 침입 좀비가 안전 칸을 노리고 8초 못 막으면 시민 도망(보너스 25초 꺼짐)
- 별 3개(클리어·구조 성공·체력 50%), 모든 보스 50% 분노(bossRage), 미니게임 장당 1번(중간보스 다음, 설계서 배치) + 다시 하기 무작위
- 새 미니게임: boiler(보일러·hack 변형), sniper(옥상 저격·dark 변형)
