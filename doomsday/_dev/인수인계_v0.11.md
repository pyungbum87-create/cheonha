## v0.11 (2026-11-13) — 그림 프롬프트 142장 목록의 기능을 미리 다 넣음 (그림만 넣으면 바뀜)
### ★ 그림 넣는 법 (내일)
1. 사용자에게 받은 그림을 한 폴더에 모음 (파일 이름 = 프롬프트 목록 이름 그대로)
2. `python3 _dev/import_art.py <그림폴더>` → 4포즈 자르기·얼굴 12칸·소품 6칸 자르기·fx 검은 배경 투명화·좀비/보스 anim 높이 비율 갱신까지 자동
3. 버전 올리고 배포. 없는 그림 자리는 404 한 번 확인 후 바로 건너뜀(재시도 안 함)
### 새 기능
- 새 무기 3종: water 소방 물대포(밀어내기+적심) / freeze 냉동 컨테이너(얼려서 멈춤+느리게) / fan 초대형 환풍기(회오리로 모으기). config weapons. 칸 그림 없으면 기관총 칸 + carTint 색 + 지붕 코드 장식(carDeco)

- 안전 칸: 시민 구출 미니게임에서 구한 사람 수만큼 'safe' 칸이 붙고 골드·경험치 보너스 (config safeCar). 옆 그림은 지금 train/extra/car_safe_a.png
