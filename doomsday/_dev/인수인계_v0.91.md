# 둠스데이 익스프레스 — 새 채팅 인수인계 (v0.91, 2026-11-13)

## 새 채팅 첫 메시지 (그대로 붙여넣기)
> 베파야, 둠스데이 익스프레스 이어서 하자. 깃허브 pyungbum87-create/cheonha 의 doomsday 폴더가 최신(v0.91)이고, doomsday/_dev/인수인계_v0.91.md 를 먼저 읽고 "다음 할 일"부터 진행해줘. 그림은 D:\앞으로 사용할 수 있는 게임이미지 폴더를 써도 돼. 쉬운 말로, 짧게 설명해줘.

## 기본 규칙
- 배포: github-pages-deploy 스킬. doomsday 폴더에 덮어쓰기. 테스트 주소 https://pyungbum87-create.github.io/cheonha/doomsday/
- 버전 바꿀 때 js/platform.js 의 DX.BUILD 와 index.html 의 ?v= 를 같이 바꿈 (config.js version 도)
- 사용자에게는 쉬운 한국어, 짧게, 결론 먼저. 그림 부탁은 "1단계/2단계 + 첨부할 파일 이름 + 붙여넣을 문장" 형식
- 사용량 절약: 큰 파일 통째로 읽지 말고 grep 으로 필요한 곳만

## v0.91 에서 추가
- 웨이브 사이 미니게임 5종 (js/minigame.js, 기존 그림만 사용): parcel 택배 받아치기 / golf 사장님 골프공(리듬) / sniper 지붕 저격 / boiler 보일러 압력 / supply 휴게소 보급 달리기
- 2번째·5번째 웨이브를 깬 뒤 나옴(1장은 2번째만). 배치·보상은 config.js minigames (S/A/B/C 등급 → 골드·체력·대파충전·카드)
- 시작 전 생존자 얼굴+말풍선, 끝나면 등급·보상 표시. 통계: mini_start / mini_result
- 바로 테스트: 주소 뒤에 ?mini=golf&ms=7 (게임이름, 스테이지 0~7)
- game.js: nextWave 앞에서 miniFor/startMini 로 끼워 넣음. DX._dbg.mini('parcel') 로 강제 실행
