## 구조
| 파일 | 내용 |
|---|---|
| `src/data.js` | 밸런스 표 전부 (타워, 적, 장 5개의 길과 파도, 보상). 숫자는 여기서만 고친다 |
| `src/core.js` | 게임 규칙. 화면·소리를 모르고 1/60초 고정 틱으로 돈다 (봇이 Node 에서 그대로 실행) |
| `src/plat.js` | 플랫폼 층: 화면 맞춤, 터치, 저장, 언어, 소리, 광고, 공유, 통계. 위챗·더우인 이식 때 이 파일만 손본다 |
| `src/art.js` | 그리기 도구, 코드로 그린 임시 적·지도(장마다 색과 꾸밈이 다름) |
| `src/battle.js` | 전투 화면 (타워·메뉴·이펙트·HUD·부활·일시정지) |
| `src/ui.js` | 홈·영웅·보상·설정·결과, 매일 보상, 전체 진행 |
| `build.py` | `site/` 생성 (index.html + game.js + art + music + 오프라인 sw.js, 캐시 이름 `ttbeach-빌드번호`) |
| `tools/bot.js` | 자동 플레이 봇. `node tools/bot.js 100` |
| `ART_PROMPTS.md` | ChatGPT 에 줄 1차 그림 프롬프트 |
| `lab/` | 다음 게임 후보로 남겨 둔 회색 박스 실험 2종 (올리지 않음) |

## 올리기
`python3 build.py` → `site/` 내용을 저장소 `/beach/` 에 그대로 복사(기존 내용은 먼저 비움) → 커밋·푸시. `dev/beach/site` 는 올리지 않는다.

## 광고 ID 넣는 곳
`src/plat.js` 의 `AD_UNIT={wx:'',tt:''}`. 비어 있으면 2초짜리 테스트 광고가 나온다. 광고 자리: `revive`(목숨 10으로 이어 하기), `double`(보상 2배), `gold`(2장부터 시작 골드 +150), `idle`(찜통 2시간치), `box`(무료 상자 하루 3번). 강제 광고 없음.

## 검사 (2026-11-17, 빌드 1117-02xx · 정통 타워 디펜스로 전투를 새로 만든 판)
- 봇 `node tools/bot.js`: 장 1~5 × (안 지음·보통·잘함). 안 지으면 반드시 짐, 잘함은 전 장 클리어, 보통은 1~3장 100%·4장 60%·5장 10%. 60·90·120Hz 결과 같음
- 화면: 폰 세로 크기에서 한국어·중국어 확인, 중국어 화면의 한글 누락 0건 (짓기 6종·강화·진화 12종·팔기 안내 포함)
- 그리기 포함 자동 플레이 1·3·4·5장: 오류 0
- 아직 안 한 것: 부활 화면 자동 확인, 위챗 흉내 환경 실행, 실제 폰 터치감

## 게임 구조 (타워 디펜스)
- 적은 바다(위)에서 길을 따라 마을 대문(아래)으로 온다. 길 옆 모래 자리에 타워를 짓는다(장마다 8~11자리, 길 모양에서 자동 선정)
- 타워 6종 = 퇀퇀 동네 캐릭터. 판 안에서 골드로 1→2→3단계, 그다음 두 갈래 중 하나로 진화(총 12갈래). 팔면 70% 환급
- 적 7종(꽃게·해파리·날치·복어·소라게·문어·갈매기) + 정예 + 보스 3종. 갑옷은 마법(방울이·반짝)에, 소라게는 폭발에 약하고, 갈매기는 길을 무시하고 난다
- 직접 쓰는 스킬 2개(큰 파도: 전부 밀어냄, 야자 폭탄: 누른 곳 폭발), 다음 파도 미리 부르기(골드 보너스), 2배속
- 목숨 20, 남은 목숨 18 이상이면 별 3개. 판 밖에서는 동전으로 타워 숙련을 올린다

## 아직 없는 것
6~10장, 무한 도전, 영웅 별(조각), 동네 키우기, 이벤트 장, 전면 광고, 위챗·더우인 포장. 적·지도는 코드로 그린 임시 그림
