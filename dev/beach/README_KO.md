## 구조
| 파일 | 내용 |
|---|---|
| `src/data.js` | 밸런스 표 전부 (타워, 적, 장 5개의 길과 파도, 보상). 숫자는 여기서만 고친다 |
| `src/core.js` | 게임 규칙. 화면·소리를 모르고 1/60초 고정 틱으로 돈다 (봇이 Node 에서 그대로 실행) |
| `src/plat.js` | 플랫폼 층: 화면 맞춤, 터치, 저장, 언어, 소리, 광고, 공유, 통계. 위챗·더우인 이식 때 이 파일만 손본다 |
| `src/art.js` | 그리기 도구, 코드로 그린 임시 적·지도(장마다 색과 꾸밈이 다름) |
| `src/battle.js` | 전투 화면 (타워·메뉴·이펙트·HUD·부활·일시정지) |
| `src/ui.js` | 홈·영웅·보상·설정·결과, 매일 보상, 전체 진행 |
| `build.py` | `site/` 생성 (index.html + game.js + art + 오프라인 sw.js, 캐시 이름 `ttbeach-빌드번호`) |
| `tools/bot.js` | 자동 플레이 봇. `node tools/bot.js 100` |
| `ART_PROMPTS.md` | ChatGPT 에 줄 1차 그림 프롬프트 |
| `lab/` | 다음 게임 후보로 남겨 둔 회색 박스 실험 2종 (올리지 않음) |

## 올리기
`python3 build.py` → `site/` 내용을 저장소 `/beach/` 에 그대로 복사(기존 내용은 먼저 비움) → 커밋·푸시. `dev/beach/site` 는 올리지 않는다.

## 광고 ID 넣는 곳
`src/plat.js` 의 `AD_UNIT={wx:'',tt:''}`. 비어 있으면 2초짜리 테스트 광고가 나온다. 광고 자리: `revive`(목숨 10으로 이어 하기), `double`(보상 2배), `gold`(2장부터 시작 골드 +150), `idle`(찜통 2시간치), `box`(무료 상자 하루 3번). 강제 광고 없음.

## 검사 (2026-11-17, 빌드 1117-10xx)
- 봇 `ONLY=all node tools/bot.js`: 장 1~10. 안 차리면 반드시 짐. 잘하는 봇은 1~9장 100%, 10장은 약 25~40%(마지막 장은 숙련을 더 올려야 함). 보통 봇은 1~3·6장 100%, 4·5·9·10장 13~25%, 7·8장 0% → **뒷장 난이도는 사람이 해 본 뒤 다시 맞춰야 한다**
- 화면: 폰 세로 크기에서 한국어·중국어 전 화면(안내서 4쪽, 가게 6종 차리기, 새 메뉴 12종, 팔기, 부활, 결과) 확인, 중국어 화면의 한글 누락 0건
- 그리기 포함 자동 플레이 6·7·9·10장: 오류 0. 음악 3곡·효과음 30종 재생 오류 0
- 위챗 흉내 환경(`dist/wx/game.js` + 가짜 wx): 화면 맞춤, 터치로 가게 차리기, 파도 시작, 숨기면 자동 일시정지, 저장, 통계 호출 확인. 진짜 위챗 개발자 도구에서는 아직 안 돌려 봄
- 아직 안 한 것: 실제 폰 터치감, 사람 귀로 듣는 소리 확인, 더우인 흉내 환경

## 위챗·더우인 포장
`python3 build.py` 가 `dist/wx/`, `dist/tt/` 를 만든다(각 약 440KB, game.js + game.json + project.config.json + art). `project.config.json` 의 appid 와 `src/plat.js` 의 `AD_UNIT` 을 채워 개발자 도구에서 연다. `site/`·`dist/` 는 빌드 결과물이라 저장소에 올리지 않는다.

## 게임 구조 (타워 디펜스)
- 손님은 바다(위)에서 길을 따라 마을 대문(아래)으로 온다. 길 옆 모래 자리에 가게를 차린다(장마다 8~12자리, 길 모양에서 자동 선정)
- 판 안에서 골드로 1→2→3단계, 그다음 새 메뉴 두 가지 중 하나(총 12가지). 팔면 70% 환급
- 손님 8종(꽃게·해파리·날치·복어·소라게·문어·갈매기·거북) + 정예 + 보스 4종
- 직접 쓰는 것: 큰 파도(전부 밀어냄), 왕수박(누른 곳을 한꺼번에 먹임), 다음 파도 미리 부르기(골드 보너스), 2배속
- 장 10개(길 10종, 색 5종). 판 밖에서는 동전으로 가게 숙련을 올린다. 안내서 4쪽

## 움직임 (빌드 1117-11xx 부터, `src/battle.js` 의 GAIT · animEnemies · drawEnemies)
그림은 가만히 선 모습 한 장만 받고, 움직임은 전부 코드가 만든다.
- 걸음은 "간 거리"에 맞춰 돈다: 느려지면 걸음도 느려지고 멈추면 걸음도 멈춘다(발이 미끄러지지 않음)
- 종마다 걸음새가 다르다(`GAIT` 표): 게 종종걸음, 해파리 오므렸다 펴기, 날치 통통 튀기, 복어 뒤뚱, 소라게 끌기, 문어 말랑, 갈매기 활공, 거북 느릿, 정예·보스 쿵쿵(먼지)
- 먹으면 용수철처럼 움찔하고, 배부름만큼 통통해진다. 방향을 바꾸면 몸이 돌고 가는 쪽으로 기운다
- 바다에서 솟아 나오며 등장, 배부르면 폴짝 뛰고 왔던 길로 통통거리며 돌아간다(`en_이름_full` 그림이 있으면 그걸 씀)
- 큰 파도·부활의 밀어내기는 순간이동이 아니라 빙글 돌며 떠밀려 간다(규칙 쪽 `kb`)
- 가게는 던질 때 손님 쪽으로 기울었다가 용수철처럼 돌아오고, 던진 간식은 바닥 그림자가 따라간다
- 화면 주사율이 60Hz 보다 높아도 틱 사이를 이어 그려 끊기지 않는다
- 확인한 것: 연속 장면 캡처로 동작·오류 0건. 사람 눈으로 본 자연스러움은 아직 확인 전

## 소리 (빌드 1117-10xx 부터)
- 음악·효과음 모두 `src/plat.js` 에서 코드로 합성한다. 음원 파일이 없어 용량이 1.7MB → 0.7MB 로 줄었고 저작권 표기도 필요 없다
- 음악 3곡: `menu`(느긋), `play`(전투), `boss`(보스 파도). 악보는 `SONGS` 표의 5음계 숫자
- 효과음: 타워별 발사음, 연속 처치 때 한 계단씩 올라가는 동전 소리, 폭발 3종, 파도 나팔 등
- 사람 귀로는 아직 아무도 들어 보지 않았다(자동 검사는 재생 오류 0건만 확인)
