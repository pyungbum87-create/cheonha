- 테스트 주소: https://pyungbum87-create.github.io/cheonha/beach/  (한국어로 보기: 끝에 `?lang=ko`, 설정에서도 바꿀 수 있음)
- 기획서: https://claude.ai/artifact/K5x7BMHFzr7cv9X7QRKJ6G · 시리즈 설계서: https://claude.ai/artifact/4iYUuvcCRffqksrTfJ2C4Q

## 구조
| 파일 | 내용 |
|---|---|
| `src/data.js` | 밸런스 표 전부 (영웅, 적, 장 5개, 카드, 보상). 숫자는 여기서만 고친다 |
| `src/core.js` | 게임 규칙. 화면·소리를 모르고 1/60초 고정 틱으로 돈다 (봇이 Node 에서 그대로 실행) |
| `src/plat.js` | 플랫폼 층: 화면 맞춤, 터치, 저장, 언어, 소리, 광고, 공유, 통계. 위챗·더우인 이식 때 이 파일만 손본다 |
| `src/art.js` | 그리기 도구, 코드로 그린 임시 적·배경 |
| `src/battle.js` | 전투 화면 (이펙트, HUD, 카드·부활·일시정지) |
| `src/ui.js` | 홈·영웅·보상·설정·결과, 매일 보상, 전체 진행 |
| `build.py` | `site/` 생성 (index.html + game.js + art + music + 오프라인 sw.js, 캐시 이름 `ttbeach-빌드번호`) |
| `tools/bot.js` | 자동 플레이 봇. `node tools/bot.js 100` |
| `ART_PROMPTS.md` | ChatGPT 에 줄 1차 그림 프롬프트 |

## 올리기
`python3 build.py` → `site/` 내용을 저장소 `/beach/` 에 그대로 복사(기존 내용은 먼저 비움) → 커밋·푸시. `dev/beach/site` 는 올리지 않는다.

## 광고 ID 넣는 곳
`src/plat.js` 의 `AD_UNIT={wx:'',tt:''}`. 비어 있으면 2초짜리 테스트 광고가 나온다. 광고 자리: `revive`(방파제 복구), `double`(보상 2배), `reroll`(카드 다시 뽑기, 무료 1번 뒤), `idle`(찜통 2시간치), `box`(무료 상자 하루 3번). 강제 광고 없음.

## 통계 이벤트 (관리자 화면에 같은 이름으로 등록)
`app_open` `load_done` `stage_start` `stage_clear` `stage_fail` `stage_quit` `ad_open` `ad_reward` `reward` `hero_up` `share` `app_hide` `draw_error`

## 검사 (2026-11-17, 빌드 1117)
- 봇: 장 1~5 × 3가지 실력, 판 길이 2.6~4.8분, 초반 30초 사망 0, 60·90·120Hz 결과 같음
- 화면: 폰 세로 크기에서 한국어·중국어 전 화면 확인, 중국어 화면의 한글 누락 0건
- 그리기 포함 전 장 자동 플레이: 오류 0. 필살기 6종·큰 파도·먹물·부활 강제 발생 포함
- 핵심 그림 3번 실패시켜도 로딩 화면에서 기다렸다가 진입, 오프라인 캐시는 `ttbeach-` 하나만 생성
- 아직 안 한 것: 위챗 흉내 환경 실행(위챗 포장 단계에서), 실제 폰 터치감

## 기획서와 달라진 점
- 그리기는 PixiJS 대신 캔버스 2D (작업 환경에서 PixiJS 를 받을 수 없었고, 위챗·더우인에 그대로 올라가는 방식)
- 장은 5개부터, 1장은 12파도로 짧게 (첫 판을 3분 안에 이기고 반짝이 합류)
- 영웅 합류: 반짝 1장, 둥둥 2장, 쫑쫑 4장 클리어 (기획서는 1·3·5장)
- 각성은 카드 4장 (기획서 5장: 봇 검사에서 보통 사람은 각성을 거의 못 봐서 낮춤)
- 체력(만두) 제한 없음, 2배속 버튼 추가, 문어 먹물은 영웅을 눌러 닦기
- 아직 없는 것: 성게·갈매기, 해적 거북 보스, 영웅 별(조각), 동네 키우기, 이벤트 장, 무한 도전, 전면 광고
