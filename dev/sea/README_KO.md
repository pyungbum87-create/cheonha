## 핵심 재미
- **탁 트인 바닷속**: 길을 파 놓지 않는다. 적이 가는 방향은 흐르는 플랑크톤 빛 알갱이·옅은 물살로만 보이고, 준비 중·웨이브 시작·자리 고를 때만 물길이 잠깐 또렷해진다
- **떠 있는 바위섬** 위에만 수호탑 5종: 산호 궁수(물리 연사) · 거품 구슬(둔화) · 해파리 등대(연쇄 번개, 투명 적 드러냄) · 소라 대포(범위, 3판부터) · 룬 등불(증폭, 6판부터). 1→2→3→4단계(각성)
- **수문**: 갈림길에서 적이 갈 쪽. 해류가 2웨이브마다 바뀌고, 🔑 열쇠(2웨이브마다 1개)로 직접 돌림
- **해류 띠**(적 가속) · **거품 기둥**(지나가는 적을 띄워 멈춤, 뜬 적 피해 +30%)
- **영웅 가드**: 눌러서 아무 데나 옮김, 처치로 레벨업, ⚓ 내려찍기
- **양쪽 다 강해짐**
  - 판이 지날수록: 수호탑 스킬 단계(1→4), 수호탑·가드 공격력 ↑ / 적 체력 ↑, 시작 심연 변이 수 ↑
  - 판 안에서: 3웨이브마다 축복 카드 3장 중 1장 + 심연 변이 1개(보호막·재생·분열·투명 등)
- 적 8종 + 정예 + 보스(심연 아귀왕: 부하 소환 → 빛 끄기 → 정예 소환)
