## 대원 합체 (2026-11-17, 사용자 요청으로 구조 변경)
- **수호탑과 대원은 따로.** 수호탑은 혼자서도 싸운다(수호탑 레벨). 대원 얼굴을 누르고 수호탑을 누르거나, 수호탑 카드 아래 얼굴을 누르면 **합체**
- 합체하면 대원 특성이 더해지고(`CREW[].tr`), 정화력 ×`crewMul(대원 레벨)`. **전용 탑**(`CREW[].tw`)에 타면 **공명**: 특성 ×1.6, 정화력 ×1.3
  - 가드(대장, 전용 탑 없음): 12% 기절 · 주변 탑 +10% · 투명한 적 드러냄 / 코라: 사거리·치명 / 보글: 둔화 / 루미: 옆 적에게 연쇄 / 소라: 작은 폭발 / 아린: 공격 속도·주변 증폭
- **합체한 대원만 필살기**(아래 얼굴 버튼). 가드도 더 이상 걸어 다니지 않고 탑에 탄다(닻 내려찍기는 탄 탑 주변)
- 대원은 이야기에 따라 합류(`join`): 가드·코라 1판, 보글 2판, 루미 4판, 소라 7판, 아린 9판. 합류할 때 짧은 이야기 장면
- 강화 화면은 탭 두 개: 수호탑(혼자 싸울 때) / 수비대원(합체 시). 대원 얼굴 그림은 `art/crew_<id>` 로 넣으면 바로 쓰임(없으면 색 원 + 첫 글자)
- 1판 튜토리얼 9단계(가드 옮기기 대신 코라 합체 → 필살기 → 가드 합체)

## 게임의 중심 (2026-11-17 확정) — 이 한 줄에서 전부 나온다
**"수비대원들이 물든 바다 생물을 정화해서 우리 편으로 만든다."**
- **대원 = 수호탑 = 스킬** (`data.js CREW`): 가드(대장·닻 내려찍기) · 코라(산호 궁수·집중 사격) · 보글(거품 구슬·거품 폭우) · 루미(해파리 등대·번개 폭풍) · 소라(소라 대포·일제 포격) · 아린(룬 등불·결계의 노래). 그 대원의 수호탑을 하나라도 지어야 스킬이 열리고, 위력은 그 수호탑의 수·단계를 따라간다(`core.js crewSkill`). 강화 화면도 대원 단위
- **정화** (`data.js PURE`, `core.js purify/allyTick`): 체력 = 오염도. 다 씻기면 맑은 색(빌드가 색을 돌려 `en_*_p` 를 만든다)으로 돌아와 잠깐 돕는다 — 치어: 진주 +1 · 게: 2.5초 길막이 · 뱀장어: 주변 3마리 감전 · 가오리: 길을 거슬러 돌진 · 정예: 4초 길막이+기절
- 수호탑을 누르면 화면 아래(탑이 아래쪽이면 위)에 카드 한 장: 이름·대원·단계·강화·판매. 건설도 같은 카드에서 고르고 "건설". 사거리 원은 그리지 않는다
- 준비 중에도 가드를 옮길 수 있다
- 난이도(1~6판): 잘하는 봇 6/6(★2.7) · 보통 5/6(★2.0) · 못하는 봇 1/6. 사람 기준으로 다시 봐야 한다

## 이야기 (2026-11-17 확정)

구역: 빛 잃은 산호 숲(아귀왕) → 가라앉은 항구(강철 거북) → 열수 분출구(용암 투구게 여왕) → 해초 미궁(대왕오징어) → 심연의 문(심연의 핵). 문구는 `data.js` 의 `PROLOGUE`, `AREAS[].intro/end`

## 짜임새
- **50판 = 5구역 × 10판.** `stageInfo(i)` 가 규칙으로 만든다(1구역만 `STAGE_FIX` 로 손질). 구역마다 물빛(`tint`)과 장치(해류·거품 기둥)가 다르다. 구역을 더하려면 `AREAS` 에 한 줄
- **적: 모든 몹에 스킬 하나** (`ENEMIES`): 치어 떼 가속 · 철갑게 껍질 닫기 · 뱀장어 돌진 · 가오리 투명 · 아귀 치유 · 오징어 먹물 · 투구게 분열 · 거북 보호막 재생 · 해마 기사 지휘. 보스 5종은 `ph`(체력 비율별 패턴: 소환·먹물·마비·보호막·가속·은신·회복)
- **우리 쪽 스킬**: 수호탑 고유 스킬(판이 지나며 Lv1→5) + **4단계 각성 두 갈래**(`BRANCH`, 10가지) + **지휘 스킬 3종**(`CMD`: 닻 내려찍기 / 어뢰 폭격 2판부터 / 해일 4판부터) + 판 안의 축복 카드
- **판 밖 성장**: 코인으로 수호탑 5종·가드 숙련(1마다 +7%, 최대 40). 판마다 권장 숙련 표시
- **보상**: 판 보상(별에 따라) + 첫 클리어 보너스 + 출석 7일 + 하루 미션 3개. 도감(적·수호탑·지휘 스킬), 이야기 다시 보기
- 화면: 홈 · 이야기 · 지도(구역 넘기기) · 강화 · 도감 · 보상 · 전투

## 밸런스 기준과 손잡이 (`data.js`)
- 한 판 4~6분, 8~13웨이브. 별은 **남은 생명** 18↑ ★3 · 10↑ ★2
- 적 체력 = `HPK × 권장 숙련 배수 × SAW(구역 안 톱니) × (1 + 구역×HPA)`. 예산(적 수)은 `BUDK`·`BUDCAP`. 튀는 판은 `EASE`
- 권장 숙련 `recLv = 1 + 판×0.5`. 숙련 비용 `lvCost`, 판 보상 `REWARD`·`firstBonus` 는 "첫 클리어 보상만으로 권장 숙련의 80~130%" 가 되게 맞춤
- 값 바꿔 보기: `bash tools/try.sh HPK HPA BUDK BUDCAP`(표본 19판) → 전체는 `bash tools/sum.sh`

- **탁 트인 바닷속**: 길을 파 놓지 않는다. 적이 가는 방향은 흐르는 플랑크톤 빛 알갱이·옅은 물살로만 보이고, 준비 중·웨이브 시작·자리 고를 때만 물길이 잠깐 또렷해진다

- **수문**: 갈림길에서 적이 갈 쪽. 해류가 2웨이브마다 바뀌고, 🔑 열쇠(2웨이브마다 1개)로 직접 돌림

- **양쪽 다 강해짐**
  - 판이 지날수록: 수호탑 스킬 단계(1→4), 수호탑·가드 공격력 ↑ / 적 체력 ↑, 시작 심연 변이 수 ↑
