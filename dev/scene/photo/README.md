# 团团小镇闹哄哄 — 사진 소동 모드 (20단계)

언제든 촬영할 수 있고, 남긴 문제가 사진에 그대로 남는 새 방식. 공개 게임 `/scene/` 과 분리되어 있다.

- `src/stages.js` 단계 데이터 (문제 5개, 그림, 규칙, 대사). 단계 추가는 여기만 고친다.
- `src/engine.html` 화면과 엔진 (규칙 실행, 사진, 사진첩, 기념관)
- `art/` 이 모드 전용 그림. 나머지는 `../art/` 재사용
- `build.py` → `site/` 생성 (`site/` 는 커밋하지 않음)

## 검사
```
python3 build.py
node qa.js                 # 그림 키, 대상, 32개 사진 도달, 제목 중복
node play.js <저장폴더>      # iPhone 13 실제 터치로 20단계 완주
```
규칙: 문제 5개는 서로 막으면 안 된다(32조합 모두 가능). 반전은 `tw` 플래그로 한 번만 실패시키고 두 번째에 성공시킨다.
광고 없음. `TEST_OPEN_ALL` 은 시험용 전체 개방이다.

## 난이도
`src/stages.js` 끝의 `diff`, `time`, `gate`(친구 찾기), `under`(가려진 물건), `decoy`(방해물)로 조절한다. 1단계만 쉽고 이후 힌트·자동 흔들림·허용 범위가 줄어든다.

## 광고
`src/engine.html` 의 `adAdapter` 만 위챗(`wx`)·더우인(`tt`) 광고로 바꾸면 된다. 지금은 시험용 가짜 광고다.
보상형 우선, 전면 광고는 `INTERSTITIAL_ON=false`. 광고 없이도 사진 저장과 다음 단계는 항상 가능. 연령 확인 전에는 `adAdapter.allowed()` 를 false 로 둔다.

## 문제 수
단계마다 사진 제목을 정하는 기본 문제 5개(`probs`)에 추가 미션(`extra`, `SIDE` 표)을 더해 8~10개다. 황금 사진은 전부 해결해야 하고, 사진첩은 기본 문제 기준 32종을 유지한다.

## 출시 준비 (2026-11-16)
- 첫 화면은 핵심 그림만 받고(약 0.5MB), 단계 그림은 그 단계를 열 때 받는다. 느리면 로딩 막대와 안내, 실패하면 최대 7번 다시 받고 25초 뒤에는 그대로 진행.
- 빌드 번호(`BUILD`)를 그림·음악 주소에 붙여 새 버전이 바로 반영된다. 메뉴 아래와 설정에 표시.
- 언어: 중국어 기본. 설정에서 `中文 + 한국어`(확인용)로 바꿀 수 있다. `?lang=ko` 미리보기.
- 단계는 앞 단계를 찍어야 열린다. 시험용 전체 열기는 주소 끝에 `?all=1`.
- 설정: 음악, 효과음, 진동, 언어, 게임 방법, 개인정보 처리방침, 진행 초기화(두 번 눌러 확인). 메뉴 아래 健康游戏忠告.
- 앱을 내리면 시간이 멈추고 돌아오면 `继续` 창. 30분마다 휴식 안내.

## 캔버스판 (위챗·더우인 미니게임용) — 2026-11
위챗·더우인 미니게임은 화면 전체를 "캔버스" 한 장에 직접 그려야 해서, 같은 게임을 캔버스 전용으로 다시 만들었다.
- 원본: `src/game.js` (웹·위챗·더우인 공용, 한 파일). 단계 자료는 기존 `src/stages.js` 그대로.
- 만들기: `python3 build.py` → `node qa.js` → `python3 build_canvas.py`
  - `canvas/web` 휴대폰 브라우저용 (공개 주소 `/town2/`)
  - `canvas/wx` 위챗 개발자 도구에서 여는 폴더, `canvas/tt` 더우인 개발자 도구에서 여는 폴더
  - 주 패키지 약 2.7MB(4MB 제한 이내), 이야기 그림(`story`)과 음악(`audio`)은 필요할 때 받는 별도 묶음
- 검사: `node play_canvas.js <포트>` (20단계 실제 터치 + 중국어 화면에 한글 0건), `node wx_smoke.js wx|tt <포트>` (가짜 위챗/더우인 환경)
- 광고 ID 넣는 곳: `src/game.js` 맨 위 `AD_UNIT.rewarded`. 비워 두면 3초 테스트 광고.
- `project.config.json`의 `appid`는 계정 발급 후 채운다.
- 글꼴은 휴대폰 기본 굵은 글꼴 사용(미니게임에서는 외부 글꼴을 못 받음).

### 미션 (2026-11-17 추가)
- 오늘의 미션 3개: 날짜로 정해져 모두에게 같음. 첫째는 늘 "사진 3장 찍기", 나머지 2개는 목록(소동 해결, 새 사진, 황금 사진, 숨은 스티커, 서로 다른 단계, 아이템 사용)에서 고름.
- 보상은 손전등·시계만(복 스티커는 황금 사진 10장·20장 때만). 광고 보면 2배. 3개 다 받으면 보너스(손전등+시계).
- 도전 과제 12개: 황금 사진 5/10/15/20, 숨은 스티커 5/10/20, 사진 30/100/200, 단계 10/20.
- 홈 화면 '미션' 버튼에 받을 보상이 있으면 빨간 점.
- 공유하기는 미션 보상에 넣지 않음(위챗 규정상 공유 유도 보상 금지).
- 첫 실행: 설명 없이 바로 1단계(손가락 안내). 게임 방법은 설정에. 2단계 처음 시작할 때 아이템 안내 한 번.
- 통계 이벤트 추가 등록: first_open, mission_done, mission_claim, mission_bonus, ach_claim
