# 조선 디펜스: 임진왜란 — 빌드 안내

## 폴더
- `web/` : 웹(모바일 브라우저) — index.html + game.js
- `wx/`  : 위챗 미니게임 — game.js, game.json, project.config.json (appid 교체 필요)
- `tt/`  : 더우인 미니게임 — game.js, game.json
- 그림을 넣을 때: 각 폴더에 `res/` 를 만들고 PNG를 넣은 뒤 game.js 의 `IMG_LIST` 에 이름을 추가

## 출시 전 확인 목록 (사용자가 직접)
1. 광고 단위 ID: game.js의 AD_UNIT 두 줄을 위챗·더우인 관리자 화면에서 받은 ID로 교체 (없으면 2초 테스트 광고)
2. 통계 이벤트 등록: 아래 표의 이벤트 이름을 위챗·더우인 관리자 화면에 같은 이름으로 등록
3. 위챗: 소규모 게임 계정(개인 주체 가능·내구매 불가), ICP 비안, 软著(또는 전자 저작권 인증), 「用户隐私保护指引」 작성, game.json의 분包 그대로 업로드
4. 판호: 내구매가 없고 광고만 쓰므로 현재 기준으로는 필요 없음 (규정은 바뀔 수 있어 제출 직전 재확인)
5. 한국 등급: 웹 공개는 문제 없음. 앱마켓·플랫폼 유통 시 마켓의 자체등급분류(IARC) 또는 게임위 등급 확인
6. 그림: ChatGPT 생성 이미지는 OpenAI 약관상 사용자에게 권리가 넘어오고 상업 이용 가능. 다만 AI 그림의 저작권 보호는 나라마다 불확실하므로 원본 프롬프트·생성 기록을 보관
7. 음원: Pixabay (상업 무료·표기 불필요). 내려받은 페이지 주소를 따로 기록해 두면 분쟁 시 증빙
8. 중국판: 일본 갑옷·역사 표현은 중국 심사 기준으로 다시 검토 (척계광 테마로 갈아 끼우기 계획)
9. 게임 이름 상표 검색 (한국 KIPRIS, 중국 商标局)

## 광고 단위 ID 넣는 곳
game.js 에서 `AD_UNIT` 을 찾아 `adunit-xxxx…`(위챗), `xxxx…`(더우인)을 실제 ID로 바꿉니다. ID가 없으면 2초 테스트 광고가 나옵니다.

| share | 공유 | – |
| guide_open | 안내서 열기 | from |

| app_hide | 앱 내림 | sc |
| history_open | 역사 카드 열기 | k |
| perk | 장수 기술 선택 (k) |
| first_open | 첫 실행 (lang, platform) |
