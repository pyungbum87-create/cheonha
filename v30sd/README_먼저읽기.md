# 천하등용 / 天下登用 — v28 릴리스 안내

기준 버전: v25 원본 파일. v28은 앞선 단계 변경 사항을 모두 포함합니다.

## 추가한 내용
v26+v27 개선 누적. 각 시나리오에 라운드당 한 번의 소규모 전투 이벤트 추가. 시나리오 선택창에 이벤트 설명 표시. 난이도와 광고 보상 유지.

## 유지한 요소
- 게임 화면 내부 좌표 640×360, 유닛 배치 8×3 (24칸)
- 캐릭터 초상화 1024×768 (8열×6행), 몹 이미지 769×112의 기존 잘라내기 좌표
- v25의 7명 신규 초상화, 몹 8종, 5개 배경 테마
- 난이도 4단계, 시나리오 별점, 등용 및 합성, 광고 보상 **데모**
- 한국어 index.html / 중국어 zh.html / PWA 캐시 버전 v28

## 사용법
압축을 해제하고 정적 HTTPS 웹 서버에 폴더 전체 업로드. PC 로컬 파일(file://)보다 웹 서버 실행을 권장합니다.
스마트폰은 가로 화면에 최적화되어 있습니다. 광고는 시뮬레이션이며 실제 수익은 발생하지 않습니다.

## 미검증 / 출시 전 조치
- 실제 위챗 미니게임 런타임 포팅 및 SDK 연결
- Android/iOS 기기에서 프레임률, 발열, 터치, 광고 표시 확인
- 인터넷 없는 상황에서 PWA 오프라인 재접속 검증
- AI 생성 일러스트와 잔존 기존 원화 상업 이용 저작권·유사성 검증
- 난이도, 반복 플레이 및 광고 보상 적절성에 대한 실제 이용자 테스트
