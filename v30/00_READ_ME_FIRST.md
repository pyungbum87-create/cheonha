# 천하등용 v29 관문 돌파 통합 — 클로드 인수인계

**최신 전체본 하나**: `Cheonha_v29_Legion_Integrated_Latest.zip`
기준: 천하등용 v28 실행판 + `Cheonha_GateBreak_Latest_for_Claude.zip`.

## 이번 변경
- `index.html`, `zh.html`: 각 시작 화면에 관문 돌파 / 军团征战 메뉴 버튼 1개 추가. 클릭 시 `legion.html` / `legion-zh.html`로 이동. **원본 v28 전투 계산·화면 로직은 변경 없음**.
- `legion.html`, `legion-zh.html`: 한국어/중국어 독립 관문 게임 진입 페이지. 나가기 시 해당 언어의 본 게임으로 복귀. 이미지 및 전투 규칙은 독립 모듈 로드.
- `legion_orders.js` (**신규**): 군령 카드 4종 (선봉 돌격/철벽 방진/책략 집중/후방 지원). 기존 `C.D.traits`의 ally-only modifiers로 등록; 게이트 무작위 조건으로 나오지 않도록 unlock을 높게 설정.
- `legion_ui.js`: 편성 화면에 군령 카드 선택 메뉴, 선택 저장 및 전투 시작 시 옵션 전달. 군령은 출진 시 1개만 적용. **피해 계산/스킬 발동 엔진은 건드리지 않음**.
- `sw.js`: 새 파일과 에셋을 포함하고 캐시 키를 `cheonha-v29-legion`으로 증가.
- `art/legion/*.webp`: 클로드가 정한 파일명 및 키 그대로 보존. 신규 파일명 임의 변경 없음.

## 전투 계산 수정 여부
- **`legion_core.js` 원본과 바이트 완전 동일.** SHA-256 `2e38e50f06de2153e1785f68c54a545a616bb3afbd2314e406b9b671aaf03b4c`
- **step, dmg, cast 수정 없음.** 새 카드 효과는 기존 `newBattle(...,{traits:[...]})` 경로와 기존 데이터 modifier 기능을 사용함.
- v28 메인 코드의 전투 규칙도 전혀 수정하지 않음(시작 화면 메뉴·진입 라우팅만 변경).

## 검증
- 한국어/중국어 게임에서 **관문 목록 → 편성 → 군령 카드 팝업 → 카드 선택 → 3인 편성 → 전투 진입** 테스트 통과 (독립 브라우저, 인라인 자산 테스트).
- 철벽 카드 선봉의 피해 배율 `1.1 → 0.935` (×0.85), 적군의 배율은 동일함을 확인.
- 양국어 메인 게임 시작 화면에서 신규 버튼/기존 시나리오 버튼 표시, 브라우저 JS 예외 0건.
- 새 WebP 27개 로드, Node 문법 검사, PWA 캐시 등록 경로 존재 검사 통과.
- 실제 HTTP 주소/로컬 서버 실행은 테스트 환경의 접속 정책으로 막혀 **미검증**. 파일 탐색기에서 열기, 실기기/PWA 복구, 위챗 SDK는 미검증.

## 현재 설계의 의도적 한계 및 주의
- **메인 디펜스와 관문 돌파가 메뉴로 연결된 단계**이며 게임 내 성장 재화·장수 보유 목록은 공유하지 않음. `cheonha_legion_v2`에 관문 전용 기록 보존. 본 게임의 저장 데이터는 건드리지 않음.
- `legion.html`의 인물 데이터 테이블은 기존 테스트 페이지에 포함된 v28 장수표 복사본. 향후 장수 능력치 변경 시 동기화 작업 필요.
- **광고는 실제 광고가 아닌 확인창 기반 테스트 보상**만 제공. 광고 SDK, 광고 완료 검증, 계정·정산 기능은 미구현.
- 중국 위챗 미니게임 변환 전환, 저작권 검토와 네트워크/성능/저장/광고 회귀 테스트는 별도 필요.
- 군령 카드는 현재 제한 없는 전투 전 선택 기능; 실제 밸런스·재화 획득 최적화는 아직 미검증.

## 테스트 방법
1. 압축을 모두 같은 폴더에 풀고 **HTTP 정적 서버에서** `index.html` 또는 `zh.html` 열기 (로컬 파일 실행보다 안정적).
2. `관문 돌파/军团征战` → 첫 관문 선택 → 군령 카드 1개 선택 → 장수 3명 편성 → 출진.
3. 지도 좌상단 `나가기/返回`를 눌러 기존 게임으로 복귀 확인.
4. 두 모드 저장값 분리 확인. 광고 버튼은 테스트용이고 실제 광고가 나오지 않는다고 안내.
