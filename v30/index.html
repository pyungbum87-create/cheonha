천하등용

장수를 등용하고, 합쳐서 키우고, 인연을 찾아 성을 지켜라

불러오는 중…

전장 보급·전투 공적 추가 보상은 선택형 광고로 준비했습니다 (브라우저는 테스트 모드)

등용 금 30으로 장수를 랜덤 등용합니다. 대부분 병졸, 가끔 무장이 나옵니다.
합성 장수를 눌러 고른 뒤 합성. 같은 장수 2명, 같은 세력·같은 등급 3명, 또는 같은 등급 아무나 4명이면 한 단계 위 장수가 나옵니다. 전설은 3명 중에서 직접 고릅니다.
배치 장수를 끌어서 다른 칸으로 옮기거나 자리를 바꿉니다. 매력이 높은 장수는 붙어 있는 칸을 강화합니다.
인연 정해진 장수들을 함께 배치하면 효과가 켜집니다. 도원결의, 오호대장군, 와룡봉추 등. 오른쪽에 켜진 인연이 표시됩니다.
히든 특정 세 장수를 모으면 고른 장수 정보창에 히든 버튼이 뜹니다. 신화 장수는 도감에서 조합이 공개되지 않으니 직접 찾아보세요.
패배 성 밖 적이 80명을 넘으면 함락. 5라운드마다 오는 적장은 75초 안에 잡아야 하고, 놓치면 성벽이 하나 깎입니다.
무기 창은 빠른 찌르기, 활은 포물선 화살, 쇠뇌는 연속 2발, 검은 검기, 대도(관우·여포 등)는 주변 적까지 베기, 철퇴는 충격파, 부적은 따라가는 기탄, 백우선은 바람으로 둔화. 장수 정보창에서 무기를 볼 수 있습니다.
기술 무장 이상은 가장 높은 능력치에 따라 기술을 씁니다. 무력: 강타 → 일섬 → 무쌍 / 통솔: 일제사격 → 화살비 → 돌격 명령 / 지력: 혼란 → 화계 → 빙결 낙뢰 / 매력: 고무 → 격려 → 인덕(아군 강화) / 정치: 군자금. 등급이 오르면 기술이 바뀝니다.
세력 강화 왼쪽 위·촉·오·군웅 버튼. 누를 때마다 그 세력 장수 전체 공격력 +12%. 버튼 위 숫자가 지금까지 오른 양입니다.
자리 위·아래 줄은 적이 지나는 길을 넓게 때리고, 가운데 줄은 짧게 때립니다. 가운데는 매력 높은 장수(이웃 강화)나 사거리 긴 장수 자리로 좋습니다.
