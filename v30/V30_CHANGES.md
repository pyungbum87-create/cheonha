
## 2차 (세력별 시나리오 · 군영 분리)
- 시나리오: 위·촉·오·군웅 탭으로 세력 선택 → 그 세력 장수만 등용·합성·전설 선택. 세력마다 진행·별 따로 저장
- 시작 장수: 위 조조·허저·하후돈 / 촉 유비·관우·장비 / 오 손책·주유·황개 / 군웅 여포·동탁·화웅
- 반동탁 연합 ★3 조건(4세력)은 세력 모드에서 "전설 2명 이상과 승리"로 대체
- 군영: 끝없는 전장 / 시나리오·위 / 촉 / 오 / 군웅 5개로 분리, 공적도 따로 적립(광고 추가 공적 포함)
- 군영 비용 대폭 상향: 군자금 80→7,268 · 정예 훈련 100→821,204 · 병법 120→8,014 · 인재 1,500/6,000 · 성벽 2,500/9,000
- 오늘의 전장 숨김

## 3차
- 군영 하루 공적 한도 100 (끝없는 전장·세력 4곳 각각, 광고 추가 공적은 한도 밖). 비용을 한도 기준으로 재설계(군영 하나 완성 약 3달)
- 군자금: 단계당 시작 금 +10, 최대 10단계 (기존 15단계 저장은 10으로 맞춤)
- 시나리오: 세력별 첫 대사·규칙 문구, 규칙의 세력 보너스는 고른 세력에 적용, 전투 중 왼쪽 강화 버튼은 고른 세력만
- 첫 진입 설명 카드: 시나리오·끝없는 전장·관문 돌파
- 관문 돌파: 탑 층 패널 지도(1~10층, 적장 얼굴·별), 합성 북·징·타격 효과음과 전투/대기 BGM(음소거 버튼 ♪)

## 4차 (쇼츠·연출)
- 합성 연출: 전설 등장 / 신화 각성 / 초월 ✦ — 빛기둥·회전 광선·충격파·화면 섬광·큰 붓글씨 자막
- 쇼츠 녹화 모드: 첫 화면 "🎬 쇼츠 녹화 모드(세로)" → 세로 화면에서도 진행, 위 로고·아래 실시간 자막(라운드·인연·합성)
- 관문 돌파: 모든 스킬에 효과 — 베기 초승달·회오리·충격파·화염·화살비·술법진·기절별·회복 입자·버프 오라 + 스킬 색 화면 섬광

## 5차 (화면 개편 1단계)
- 장수를 누르면 왼쪽 아래 정보창 대신 장수 위(맨 윗줄은 아래)에 말풍선: 이름·초월·세력/등급/역할/무기·공격/사거리/기술 + [합성][판매][히든] 버튼
- 하단 버튼 5개 → 등용·명성 2개만 남김 (합성·판매·히든은 말풍선 안)

## 6차 (화면 개편 2단계 · 좌표 변경)
- 하단 바 제거 → 전장이 화면 높이 거의 전체 사용. 적 길: PL56 PR516 PT46 PB334 / 칸: SX90 SY126 SPX56 SPY64 (8×3 유지, 저장은 칸 번호라 영향 없음)
- 사거리 ×1.3 (넓어진 전장에 맞춰 커버 범위 유지)
- 왼쪽: 강화 접기 탭(▸/◂), 시나리오는 고른 세력 버튼 하나만 / 왼쪽 아래 명성
- 오른쪽 정보 패널: 장수 초상·이름·세력·등급·역할·무기·공격·간격·사거리·기술 + 합성·판매·히든, 미선택 시 인연 목록 / 오른쪽 아래 큰 등용 버튼
- 말풍선 제거, 새 전장 배경(흙길 고리·자갈·성문·발판)
