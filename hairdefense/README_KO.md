## 실행
`index.html`을 열거나, 이 폴더를 웹 서버에 그대로 올리면 됩니다.
- 화면 아래 작은 글씨 `HAIR DEFENSE v10 · 월일-시분`이 빌드 번호입니다. 휴대폰에서 최신판인지 이것으로 확인하세요.
- `?lang=zh` / `?lang=ko` / `?lang=en` 을 주소 끝에 붙이면 언어를 바로 바꿔 볼 수 있습니다.

## v10에서 바뀐 점
| 구분 | 내용 |
|---|---|
| 주인공 | 선택한 캐릭터 그림이 화면 가운데에 크게 나옵니다. 그림 속 원래 머리카락은 지우고 게임이 7가닥을 직접 그려서, 한 가닥씩 뽑혀 날아가는 게 보입니다. 맞으면 머리가 고무처럼 늘어났다 튕기고, 땀이 흐르고, 마지막 2가닥에서는 덜덜 떨고, 0가닥이면 정수리가 반짝입니다. 까마귀가 노리는 머리카락은 미리 떨립니다 |
| 적 | 까마귀는 실제 머리카락 뿌리로, 서류는 정수리로 날아옵니다 |
| 한국어 발음 | 기기에 있는 음성 중 가장 자연스러운 것(Google·Yuna·Neural 등)을 고르고, 장난감 목소리(Eddy·Grandma 등)는 피합니다. 한국어 음성이 없으면 엉뚱한 목소리로 읽지 않고 안내 문구를 띄웁니다. 설정 화면에서 언어별로 어떤 음성을 쓰는지 보이고 시험 듣기도 됩니다 |
| 시작 화면 | 스크롤 없이 한 화면에 들어옵니다. 큰 주인공 무대에서 ‹ › 로 넘겨 보고, 잠긴 주인공은 시작 버튼이 "🪙로 열기"로 바뀝니다 |
| 설정 | 배경음악·효과음·발음·진동·언어·개인정보 처리방침·진행 초기화(두 번 눌러 확인) |
| 소리 | 배경음악(메뉴·게임 별도, 직접 합성해 저작권 걱정 없음), 퀴즈 중엔 음악이 작아지고 광고 중엔 꺼집니다 |
| 첫 판 안내 | 처음 하는 사람에게 손가락 표시로 "터치!" "옆으로 쓱 밀어요!"를 3번 보여 줍니다 |
| 로딩 | 그림을 다 받을 때까지 진행 막대, 느리면 안내, 실패하면 최대 8번 다시 시도 |

## 광고 ID 넣는 곳
`game.js`에서 `const AD_UNIT={wx:'',tt:''};` 를 찾아 따옴표 안에 보상형 영상 광고 ID를 넣습니다. 비어 있으면 2초 테스트 광고가 나옵니다.
