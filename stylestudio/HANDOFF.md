# 퍼컬 원장 — 작업 인계 메모 (v1.1, 2026-11-15)

**제목**: 퍼스널컬러 찾으러 갔을 뿐인데 원장이 된 나? (줄임말: 퍼컬 원장)
**테스트 주소**: https://pyungbum87-create.github.io/cheonha/stylestudio/
**저장소 위치**: `pyungbum87-create/cheonha` → `stylestudio/` 폴더 (index.html, avatar.js, beauty.js, sound.js, img/, PROMPTS.md)

## 파일 구성
- `index.html` — 앱 전체 (화면, 진단, 게임, 스토리, 상점, 채점 엔진)
- `avatar.js` — 전신 아바타 SVG (헤어 22, 상의 10, 하의 6, 신발 5, 소품 14, 메이크업 립9/블러셔8/섀도5, ✨고급 버전 렌더)
- `beauty.js` — 내 사진 보정(원본/자연스럽게/화사하게): 피부 매끈·화사, 다크서클, 눈 키우기, 턱선. 기기 안 처리. 진단 화면은 원본 유지
- `sound.js` — 효과음(WebAudio 합성, 파일 없음) + 배경음악(`audio/bgm_salon|diag|story|award.mp3`, 없으면 무음) + 왼쪽 아래 소리 버튼
- `PROMPTS.md` — 아직 없는 그림 프롬프트, 픽사베이 배경음악 목록
- `img/` — 모두 webp (v1.1에서 jpg→webp, 2.8MB→약 1.2MB). 심사위원(기본/happy/sad), 손님 12명 초상화(cust_01~12), 장소 배경 5장, 살롱 배경, 대표 이미지

## 핵심 시스템
1. **퍼스널컬러 진단**: 셀카 → MediaPipe(기기 안 분석, 서버 전송 없음) → 16색 천 월드컵 → 시즌 결과 → '나' 저장(localStorage `cs_me`, 얼굴 썸네일은 선택 시에만)
2. **스타일리스트 살롱 게임** (`cs_game3`): 손님(기본/중간/하드) + 부분 의뢰(전체·헤어만·메이크업만·코디만·헤어+코디·헤어+메이크업)
3. **심사위원 3명 채점 엔진** (`score()`): 체크 항목 × 가중치 × 달성도, 난이도별로 항목이 켜지고 관대함이 줄어듦. 하드는 치명적 실수가 있으면 S 불가
   - 모나(컬러): 옷·머리·립·블러셔·섀도·하의의 시즌 매칭
   - 제이(TPO): 상황별 상·하의·신발, 분위기 색, 면접 규칙(블랙 감점·네이비/차콜 가점), 헤어·메이크업 TPO
   - 하루(조화): 머리-옷 대비(겨울·봄 높음/여름·가을 낮음), 3색 규칙·60-30-10·톤온톤/톤인톤, 신발 깔맞춤, 메탈(웜=골드/쿨=실버/여름=진주), 소품 매너, 요청·금지
4. **원장 이미지 → 살롱 인기도 → 상권 경쟁**(라이벌 3곳, 대결) → 손님 수 2~5명
5. **성장 단계**: 동네 살롱 → 입소문 → 핫플 → 트렌드 세터 → 이미지 변신 아이콘
6. **스토리**: 프롤로그~최종장, 스토리 미션(3장 매거진 화보, 4장 결승 vs 레오)
7. **주간 챌린지**: 시드 고정 손님 + NPC 고스트 8명 + 도전장 링크(`?ghost=`) 비동기 대결, 점수는 코디로 재계산(조작 불가)
8. **광고 자리(테스트 화면)**: 아이템 ✨고급 버전 업그레이드, 히든 아이템 해금(3회), 코인 2배, 손님 새로고침
9. **손가락 튜토리얼**, 실시간 거울 모드, 사진 상황별 룩

## v1.3 (중국 테스트 대응)
- 중국어(简体): `lang.js`가 화면 글자를 `i18n_zh.js` 사전(약 960개)으로 바꿈. 중국어일 때만 사전을 받음. 자동 선택(브라우저 언어·중국 시간대), 홈 오른쪽 위 버튼으로 전환(`cs_lang`)
  - 새 한국어 문구를 추가하면 사전에도 추가해야 함(안 하면 한국어로 보임). 캔버스 카드·공유 문구도 번역됨
- 🪙·🪞 이모지가 깨지는 기기에선 💰·🔍로 자동 대체
- 가볍게: AI 모델(약 20MB)은 진단·거울 들어갈 때만, 게임 그림은 게임 들어갈 때 받음, 배경음악 64kbps(곡당 약 1MB)
- 실시간 거울: 얼굴을 따라 자동 확대·세로 3:4 화면, 천이 화면 끝까지, 시즌별 색 전체(+확장색)
- 손님 중복 제거, 로비 아래 '게임 처음부터 다시 하기'
- ⚠️ 중국 본토는 storage.googleapis.com(모델)·cdn.jsdelivr.net이 막힐 수 있음 → 출시 전 모델·wasm 파일을 자체 서버(또는 중국 CDN)로 옮겨야 함

## 출시 전 체크리스트 (v1.2 점검 결과)
완료: 공유 미리보기(og.jpg·설명), 아이콘·홈 화면 추가(manifest), 개인정보 처리방침(privacy.html), '내 데이터 모두 지우기',
도전장 링크 입력 검증(XSS 차단), confirm/prompt → 자체 대화상자(카톡·인스타 앱 안 브라우저 대응)

1. privacy.html 문의 이메일 입력 (`[출시 전 문의 이메일 입력]`)

4. MediaPipe 모델 주소의 `latest`를 고정 버전으로 (구글이 모델을 바꾸면 결과가 달라질 수 있음)
5. 실기기 테스트: 아이폰 사파리, 갤럭시 크롬, 카톡 앱 안 브라우저(카메라 권한), 사진 보정 결과

7. 장기 코인 소비처(살롱 인테리어 등) — 상점을 다 사면 코인이 쌓이기만 함
