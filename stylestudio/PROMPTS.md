# 퍼컬 원장 — 그림 프롬프트 모음 (v1.1)

ChatGPT에 **공통 스타일을 먼저 붙이고**, 그 아래에 각 프롬프트를 붙여 넣으면 돼요.
받은 그림은 그대로 보내 주시면 제가 자르고·줄이고(webp) 이름 붙여서 넣을게요.
**파일만 들어가면 게임에 자동 적용**되고, 없으면 지금처럼 기본 그림이 나와요.

## 0. 공통 스타일 (매번 맨 앞에 붙이기)

```
[스타일] 부드러운 한국 웹툰풍 일러스트. 깔끔한 갈색 선화, 은은한 셀 음영, 따뜻한 파스텔 톤.
지금 게임의 원장님·레오·손님 초상화와 같은 그림체. 사진처럼 그리지 말 것.
배경은 순수한 흰색(#FFFFFF), 글자·로고·워터마크·테두리 없음.
```

게임에서 A등급 이상을 받으면 결과 화면에 "변신 전 → 변신 후"가 나와요.

```

변신 후에 바뀌는 것은 헤어스타일, 메이크업, 옷, 표정과 자세뿐.
```

## 2. 신발 (4개씩 2장)

공통 문장:

```
정사각형 이미지 한 장을 2×2 칸으로 나눠 신발 4개를 각각 그려 주세요.
각 칸: 오른발 한 짝, 옆에서 45도 위에서 본 모습, 칸 가운데, 칸 사이 흰 여백 넉넉히.
상점 아이콘용. 그림자는 아주 연하게. 글자 없음. 색은 무난한 중간 톤.
```

- **신발 A** (왼쪽 위 → 오른쪽 위 → 왼쪽 아래 → 오른쪽 아래): 흰 스니커즈 / 브라운 페니 로퍼 / 베이지 펌프스 힐 / 블랙 앵클부츠
  → `shoes_a`
- **신발 B**: 끈 샌들(탠 브라운) / 블로퍼 뮬(골드 장식, 크림색) / 옥스퍼드 구두(다크 브라운, 끈) / 청키 스니커즈(두꺼운 흰 밑창, 그레이)
  → `shoes_b`

## 3. 가방 (4개씩 2장)

공통 문장은 신발과 같고, "신발"을 "가방"으로, "오른발 한 짝"을 "가방 하나, 정면에서 살짝 위"로 바꿔 주세요.

- **가방 A**: 카멜 가죽 토트백 / 다크 브라운 서류 가방 / 블랙 숄더백 / 브라운 크로스백
  → `bags_a`
- **가방 B**: 크림색 체인 미니백 / 베이지 클러치 / 네이비 백팩 / 캔버스 에코백(작은 초록 잎 무늬)
  → `bags_b`

## 6. 배경음악·효과음 (픽사베이 뮤직)

픽사베이는 **상업적 사용 가능, 출처 표시 불필요**예요. 단, 음원 파일만 따로 팔거나 배포하는 건 안 되고, 유튜브 Content ID 등록도 하면 안 돼요.

효과음은 이미 **코드로 직접 만들어 넣어서 파일이 필요 없어요** (버튼, 천 고르기, 등급, 구매, 레벨업, 트로피 등).
배경음악만 아래 4곡을 받아서 보내 주세요. (mp3, 1~3분, 반복 재생되는 곡이 좋아요)

| 파일 이름 | 쓰이는 곳 | 픽사베이 검색어 | 분위기 |
|---|---|---|---|
| bgm_salon.mp3 | 로비·살롱·코디 | `cute lofi`, `cozy cafe` | 잔잔하고 귀여운 로파이, 보컬 없음 |
| bgm_diag.mp3 | 퍼스널컬러 진단 | `soft piano happy`, `bright acoustic` | 밝은 피아노·어쿠스틱 |
| bgm_story.mp3 | 스토리 장면 | `heartwarming`, `kawaii` | 따뜻하고 살짝 코믹 |
| bgm_award.mp3 | 어워드·결승·시상식 | `glamour fashion`, `elegant pop` | 화려한 패션쇼 느낌 |

팁: 곡을 고를 때 **보컬 없는 곡**, 너무 크지 않은 곡(2~4MB 이하)을 고르면 로딩이 빨라요. 크면 제가 줄여 드릴게요.
